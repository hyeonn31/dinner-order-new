Features
주요 기능
🔐

자체 인증 시스템

SHA-256 + salt 비밀번호 해싱, JWT 세션 관리(7일), 역할 기반 접근 제어(RBAC). 사전 등록 직원만 가입 허용.

🍽️

저녁 신청

오늘의 식당 선택 후 메인·사이드·음료·옵션 선택. 당일 재신청(Upsert) 가능. 마감 여부 실시간 반영.

⚙️

관리자 메뉴 설정

오늘의 식당 다중 선택, 신청 마감 토글, 당일 전체 초기화. 관리자 전용 보호 라우트.

📊

주문 취합

식당별·메뉴별 신청 현황 실시간 집계. 직원별 신청 내역 상세 조회. 관리자 전용.

📅

이력 조회

날짜별 과거 신청 이력 조회. 식당·메뉴·직원별 필터링. 데이터 영구 보존.

🏪

식당·메뉴 관리

카테고리별 식당 추가/삭제. 메뉴 항목(메인/사이드/음료/옵션/드레싱) 관리.

👥

직원 관리

직원 닉네임 추가/비활성화, 정렬 순서 관리. 직원별 신청 이력 상세 조회.

🛡️

계정 관리

전체 가입 계정 목록 조회(아이디·닉네임·역할·가입일). 계정 삭제. 관리자 전용.

Problem Solving
개발 과정에서 해결한 주요 과제
1

하드코딩 비밀번호 → 역할 기반 접근 제어(RBAC) 전환

기존 관리 페이지의 하드코딩 비밀번호 방식을 JWT 세션 + admin/user 역할 분리 방식으로 전환. 서버 라우트와 클라이언트 라우트 모두 이중 보호 적용.

2

배경 이미지 위 텍스트 가독성 확보

CSS ::before 다크 오버레이(55% 불투명도) + 카드 배경 불투명도 조정으로 밝은 배경 영역에서도 텍스트가 선명하게 보이도록 처리. shadcn/ui Select placeholder 색상도 white/70으로 커스터마이징.

3

모바일 반응형 헤더 처리

모바일(640px 미만)에서 헤더 텍스트가 잘리는 문제를 Tailwind sm: 브레이크포인트로 텍스트 숨김 처리. 로고 이미지만 표시하여 깔끔한 모바일 UI 구현.

4

역할별 홈 화면 UI 분기

useAuth() 훅의 isAdmin 값으로 렌더링 카드를 동적 분기. 일반 사용자에게는 저녁 신청 카드만, 관리자에게는 전체 기능 카드를 표시하여 UX 단순화.

5

DB 컬럼명 불일치로 인한 로그인 오류 디버깅

비밀번호 변경 시 SQL 컬럼명(password_hash vs passwordHash) 불일치로 업데이트가 반영되지 않던 문제를 스키마 확인 후 정확한 컬럼명으로 재실행하여 해결.

모바일 친화적 레이아웃. 화면 크기에 따라 헤더 텍스트 자동 숨김 처리.

역할별 UI 분기

일반 사용자와 관리자에게 각각 다른 홈 화면을 제공하여 불필요한 UI 요소 제거.
